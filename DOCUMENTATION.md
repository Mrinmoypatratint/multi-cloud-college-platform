# 📚 Project Documentation Index

Welcome to the Documentation Hub for the **Multi-Cloud College Management & Student Services Platform**. 

We maintain comprehensive documentation to ensure that developers, architects, and operators can easily understand, deploy, and contribute to this platform. This index acts as a central map to navigate all available resources.

---

## 🗺️ Documentation Directory

### 🚀 Getting Started
- **[Setup Guide](SETUP.md)**: Step-by-step instructions for getting the platform running on your local machine using Python, Node.js, or Docker.
- **[Developer Onboarding](docs/ONBOARDING.md)**: A high-level introduction to the team, the codebase, and the initial setup checklist for new developers.

### 🏗️ Architecture & Design
- **[System Architecture](docs/ARCHITECTURE.md)**: Detailed blueprints of the system design, the separation of frontend and backend concerns, and the application of SOLID principles.
- **[API Specification](docs/API.md)**: A comprehensive catalog of all RESTful API endpoints available under `/api/v1/`, including Authentication, User Management, Academic, and Attendance endpoints.

### ☁️ Infrastructure & Operations
- **[Deployment Manual](docs/DEPLOYMENT.md)**: Instructions and strategies for deploying the application to our multi-cloud infrastructure (AWS Production & Azure Staging/DR) using Terraform.
- **[Security Policy](docs/SECURITY.md)**: Details on our Security Architecture, including JWT Authentication, Role-Based Access Control (RBAC) definitions, and Audit Logging middleware.

### 🛠️ Development & Collaboration
- **[Contributing Guidelines](docs/CONTRIBUTING.md)**: Rules for branching strategies, semantic commit messages (e.g., `feat:`, `fix:`), and pull request workflows.
- **[Testing Strategy](docs/TESTING.md)**: Information on how to run backend Django test suites and frontend Vitest component tests.
- **[Troubleshooting](docs/TROUBLESHOOTING.md)**: Solutions to common development errors, such as database migration inconsistencies or CORS issues.
